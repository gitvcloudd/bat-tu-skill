## CHƯƠNG X: KHO 30 LÁ SỐ THỰC CHIẾN MANH PHÁI ĐỐI CHỨNG (MP01 - MP30)

Chương này tuyển chọn 30 kỳ án mệnh lý kinh điển được giải mã theo chuẩn mực Manh Phái của Hạ Trọng Kỳ và Đoàn Kiến Nghiệp đối chiếu từ các danh tác: *Bát Tự Trân Bảo Giảng Nghĩa*, *Manh Phái Sơ Trung Cao Cấp Mệnh Lý Học*, và *Bát Tự Luận Mệnh Bí Kiếp*. #### MP01: Trưởng Ban Tổ Chức Tỉnh Ủy — Hỏa Thổ Chế Ngự Hợi Thủy
- **Bát Tự:** Nam mệnh: **Kỷ Sửu / Bính Dần / Bính Tuất / Canh Dần**
- **Thông số thiên văn:** TST: 03:42, JDN: 2433290, Tọa độ: $36^\circ 04' N, 114^\circ 21' E$.
- **Bảng Tứ Trụ & Nạp Âm:**
  - Trụ Năm: Kỷ Sửu (Tích Lịch Hỏa) — Tân vị.
  - Trụ Tháng: Bính Dần (Lư Trung Hỏa) — Tân vị.
  - Trụ Ngày: Bính Tuất (Ốc Thượng Thổ) — Chủ vị.
  - Trụ Giờ: Canh Dần (Tùng Bách Mộc) — Chủ vị.
- **Cơ chế Manh Phái:**
  - Nhật Chủ Bính Hỏa tọa Tuất (Hỏa Khố), sinh tháng Dần, giờ Dần. Toàn cục Hỏa Thổ kết đảng cực vượng.
  - Trụ Năm có Sửu Thổ mang Quý Thủy Chính Quan ẩn tàng. 
  - Tuất ở Chi Ngày là Chủ vị quay sang **HÌNH SỬU** ở Trụ Năm (Tân vị). Đây là cơ chế dùng Hỏa Khố (quân đội, quyền lực) ở Chủ vị để hình khai và khống chế hoàn toàn Sửu Thổ (cơ quan công quyền, quan lại cấp dưới) ở Tân vị.
  - Vì Sửu là Quan Khố ở ngoài xã hội bị mình chế ngự toàn diện nên nắm quyền quản lý toàn bộ cán bộ công chức trong tỉnh (Trưởng Ban Tổ Chức Tỉnh Ủy). Vận Kỷ Tỵ bộc phát làm Phó Bí thư Tỉnh ủy.
- **So sánh Cổ Điển vs Manh Phái:**
  - *Cổ điển:* Bính sinh Dần vượng, thấu Kỷ Thổ Thương Quan, tài Quan hư phù, luận là Thân Vượng Thương Quan phối Ấn, cách cục thanh cao.
  - *Manh Phái:* Không luận vượng suy, lấy "Tuất hình Sửu" làm cơ quan tố công tối thượng, Sửu là Tặc Thần bị Hỏa Thổ Bổ Thần nuốt trọn.
- **Chấm điểm WES:** 92/100 (Hạng: THẦN CƠ).
- **Mốc thời gian thực nghiệm:** 1998 (Mậu Dần) thăng Thị ủy Bí thư; 2003 (Quý Mùi) Sửu Tuất Mùi tam hình mở kho thăng Phó Bí thư Tỉnh ủy kiêm Trưởng Ban Tổ Chức.

  - **Sửu Mùi tương xung**: Chi Ngày Mùi Thổ chủ động xung phá Sửu Thổ ở Trụ Tháng. Đây là "Chủ xung Tân", dùng mưu lược của mình để phá khóa kho bạc của thị trường.

  - *Cổ điển:* Tân sinh tháng Sửu đắc dưỡng, Mùi Thổ sinh Thân, Thủy nhiều tiết khí, luận là Tạp Khí Ấn Thụ cách.
  - *Manh Phái:* Sửu Mùi xung mở kho Tài Mộc, Tý Sửu hợp khóa dòng Thủy, quy kho tối cao.
- **Chấm điểm WES:** 94/100 (Hạng: THẦN CƠ).
- **Mốc thời gian:** 2000 (Canh Thìn) thành lập tập đoàn địa ốc; 2008 (Mậu Tý) tài sản vượt ngưỡng 10 tỷ NDT.

## CHƯƠNG XI: THUẬT TOÁN ĐỊNH LƯỢNG WES (WORK EFFICIENCY SCORE — 0 ĐẾN 100 ĐIỂM)

Để hỗ trợ AI Agent và các hệ thống máy tính tự động hóa việc chấm điểm năng lực Tố Công của một lá số Bát Tự theo Manh Phái, chúng tôi phát triển thuật toán **WES (Work Efficiency Score Engine)**.

```
+-----------------------------------------------------------------------------+
|                CÔNG THỨC GIẢI TÍCH WES (WORK EFFICIENCY SCORE)              |
|                                                                             |
|      WES = w1*C_type + w2*S_target + w3*P_host + w4*E_purity - w5*R_penalty  |
|                                                                             |
|  * C_type   (Hệ số loại hình Tố Công):     Chế/Mộ = 30đ; Hóa/Hợp = 25đ; Sinh = 20đ |
|  * S_target (Quy mô đối tượng bị bắt):     Tặc Thần vượng đắc lệnh = 25đ     |
|  * P_host   (Vị trí Chủ thể thực thi):     Tọa Chi Ngày / Chi Giờ = 20đ     |
|  * E_purity (Độ thuần khiết thế trận):     Kết đảng không bị tạp khí = 15đ  |
|  * R_penalty(Điểm phạt phản cục/xung nội bộ): Bị phản cục đập ngược = -30đ   |
+-----------------------------------------------------------------------------+
```

### 11.1. Bảng Trọng Số Giải Tích Chi Tiết `[REF-11-029]`

1. **Loại hình Tố Công ($C_{type}$ — Tối đa 30 điểm):**
   - Chế Dụng Tố Công triệt để (Hỏa Thổ chế Kim Thủy, Kim Thủy chế Hỏa Thổ): 30 điểm.
   - Mộ Khố Tố Công (Xung khai khố thu nạp cả bàn): 28 điểm.
   - Hợp Dụng Tố Công (Can Hợp, Chi Lục Hợp thâu tóm): 25 điểm.
   - Hóa Dụng Tố Công (Quan Sát hóa Ấn, Thương hóa Tài): 22 điểm.
   - Sinh Dụng Tố Công (Thực Thần sinh Tài đơn thuần): 18 điểm.
2. **Quy mô Tặc Thần bị bắt ($S_{target}$ — Tối đa 25 điểm):**
   - Tặc Thần đắc lệnh tháng, có gốc vững chắc mà bị bắt gọn: 25 điểm.
   - Tặc Thần trung bình, bị bao vây: 18 điểm.
   - Tặc Thần quá yếu ớt (bắt không bõ công): 8 điểm.
3. **Vị trí Chủ Vị ($P_{host}$ — Tối đa 20 điểm):**
   - Lực lượng bắt giặc phát xuất từ Chi Ngày (Vợ chồng, bản thân): 12 điểm.
   - Lực lượng phát xuất từ Chi Giờ (Cửa ngõ, con cái, tay chân): 8 điểm.
4. **Độ thuần khiết ($E_{purity}$ — Tối đa 15 điểm):**
   - Toàn cục thuần dương hoặc thuần âm kết đảng: 15 điểm.
   - Có 1 chữ tạp khí nhưng bị chế ngự: 10 điểm.
   - Tạp khí hỗn loạn: 3 điểm.
5. **Điểm trừ Phản Cục ($R_{penalty}$ — Phạt từ 0 đến 35 điểm):**
   - Chi Ngày xung Chi Giờ (Nội bộ đánh nhau): Trừ 15 điểm.
   - Tặc Thần quá mạnh quay lại bẻ gãy Bổ Thần: Trừ 30 điểm.

### 11.2. Mã Nguồn TypeScript / Node.js WES Engine Chuẩn Mực

```typescript
/**
 * WORK EFFICIENCY SCORE (WES) ENGINE - MANH PHAI BAZI
 * Phiên bản: 1.0.0 - Antigravity Autonomous Agent Standard
 */

export interface WorkMechanismInput {
  caseId: string;
  name: string;
  mechanismType: 'CHEDUNG' | 'MOKHO' | 'HOPDUNG' | 'HOADUNG' | 'SINHDUNG';
  targetScale: 'HUGE_VƯỢNG' | 'MEDIUM_TRUNG' | 'WEAK_SUY';
  hostPosition: { dayBranchActive: boolean; hourBranchActive: boolean };
  purityGrade: 'PURE_KẾT_ĐẢNG' | 'SLIGHT_TẠP' | 'CHAOTIC_HỖN_LOẠN';
  internalConflict: boolean;
  reverseReactionRisk: boolean; // Phản cục
}

export interface WESResult {
  caseId: string;
  name: string;
  score: number;
  grade: 'THẦN CƠ (TỶ PHÚ/NGUYÊN THỦ)' | 'CAO CẤP (C-LEVEL/ĐẠI GIA)' | 'TRUNG BÌNH (CHUYÊN GIA)' | 'TIÊU HAO (BẦN HÀN/LAO TÙ)';
  breakdown: Record<string, number>;
}

export class WorkEfficiencyEngine {
  public static calculate(input: WorkMechanismInput): WESResult {
    let cScore = 0;
    switch (input.mechanismType) {
      case 'CHEDUNG': cScore = 30; break;
      case 'MOKHO': cScore = 28; break;
      case 'HOPDUNG': cScore = 25; break;
      case 'HOADUNG': cScore = 22; break;
      case 'SINHDUNG': cScore = 18; break;
    }

    let sScore = 0;
    switch (input.targetScale) {
      case 'HUGE_VƯỢNG': sScore = 25; break;
      case 'MEDIUM_TRUNG': sScore = 18; break;
      case 'WEAK_SUY': sScore = 8; break;
    }

    let pScore = 0;
    if (input.hostPosition.dayBranchActive) pScore += 12;
    if (input.hostPosition.hourBranchActive) pScore += 8;

    let eScore = 0;
    switch (input.purityGrade) {
      case 'PURE_KẾT_ĐẢNG': eScore = 15; break;
      case 'SLIGHT_TẠP': eScore = 10; break;
      case 'CHAOTIC_HỖN_LOẠN': eScore = 3; break;
    }

    let penalty = 0;
    if (input.internalConflict) penalty += 15;
    if (input.reverseReactionRisk) penalty += 30;

    let total = Math.max(0, Math.min(100, cScore + sScore + pScore + eScore - penalty));

    let grade: WESResult['grade'] = 'TIÊU HAO (BẦN HÀN/LAO TÙ)';
    if (total >= 85) grade = 'THẦN CƠ (TỶ PHÚ/NGUYÊN THỦ)';
    else if (total >= 65) grade = 'CAO CẤP (C-LEVEL/ĐẠI GIA)';
    else if (total >= 40) grade = 'TRUNG BÌNH (CHUYÊN GIA)';

    return {
      caseId: input.caseId,
      name: input.name,
      score: total,
      grade,
      breakdown: { cScore, sScore, pScore, eScore, penalty: -penalty }
    };
  }
}
```
